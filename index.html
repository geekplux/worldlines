How to learn the whole world without flattening it.

    This atlas is a learning scaffold: a deliberately selective set of turning points and states, not a claim to contain every people or experience. Dates marked “c.” are approximate, and broad processes resist single-year labels.

    About the dates and borders

    Dates are conventional. States rarely began or ended in a single year, and modern country names are used only as stable places to stand: “China in 500 BCE” means the lands that later became China, not a nation that existed then.

    About the images

    Event pictures are the lead images of English Wikipedia articles, shown only when the file is on Wikimedia Commons. Every panel links to its source; check the file page before reusing an image.

    The project

    A static site with no build step: HTML, CSS and plain JavaScript, with all content in bilingual data files. A sibling of Art-isms.
